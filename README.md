# Разбор Yii 2

Авторский конспект фреймворка **Yii 2** по официальному [руководству](https://www.yiiframework.com/doc/guide/2.0/ru) — и справочник по самому **PHP 8+**.

**Открыть сайт → https://despro3.github.io/yii2-cheatsheet/**

Четыре страницы под разные задачи:

| Страница | Что это | Когда открывать | Файл |
|---|---|---|---|
| [**Курс по Yii 2**](https://despro3.github.io/yii2-cheatsheet/course.html) | 49 разделов, все 99 глав руководства, примеры, грабли, карточки самопроверки | читать подряд и разбираться | `docs/course.html` |
| [**Справочник Yii 2**](https://despro3.github.io/yii2-cheatsheet/explorer.html) | 20 механизмов фреймворка одной схемой, полные списки встроенного, живые демонстрации | найти нужное и кликнуть | `docs/explorer.html` |
| [**Справочник PHP 8+**](https://despro3.github.io/yii2-cheatsheet/php.html) | 27 механизмов языка одной схемой, 408 возможностей с отметкой версии, демонстрации на настоящих данных PHP | вспомнить, как устроен сам язык | `docs/php.html` |
| [**Выжимка по Yii 2**](https://despro3.github.io/yii2-cheatsheet/v1/) | ранняя редакция: то же руководство в 17 разделах вместо 49, в семь раз короче | быстро повторить | `docs/v1/index.html` |

Точка входа — `docs/index.html`: страница-хаб с карточками, откуда расходятся все страницы. Всё готовое лежит в папке [`docs/`](docs/) и открывается прямо из файла или через GitHub Pages.

## Курс

## Что внутри

- **13 частей** — от установки и структуры приложения до REST, кэширования, тестирования и производительности; порядок разделов выстроен как курс.
- **Код с подсветкой** для PHP, SQL, Bash, JS, JSON, YAML, nginx и других языков; у каждого примера — кнопка копирования.
- **Врезки**: «На заметку», «Совет», «Внимание», «Грабли», «Зачем это нужно», «Пример из жизни».
- **Проверь себя** — карточки «вопрос → ответ» в конце каждого раздела.
- **Поиск** по всем разделам (`Ctrl K` или `/`), оглавление страницы, прогресс изучения, светлая и тёмная темы, версия для печати и «всё одной страницей».
- **Памятка на одну страницу** и **глоссарий** — для быстрого «как это писалось».

Сайт не зависит от внешних скриптов: только HTML, CSS и немного JavaScript. Единственный внешний ресурс — шрифты Google Fonts (без них страница остаётся читаемой на системных шрифтах).

## Структура репозитория

```
build.py                  генератор сайта (Python 3, без зависимостей)
build_explorer.py         сборка «Справочника Yii 2»
build_php.py              сборка «Справочника PHP 8+»
src/
  catalog.py              общий движок обоих справочников: блоки, узлы карты, каркас страницы
  content/*.md            разделы курса — Markdown с расширениями
  templates/*.html        каркас страниц и хаб (hub.html)
  assets/                 style.css, app.js, favicon.svg
  diagrams/*.svg          диаграммы
  parts.json              части сайта (порядок, названия, иконки)
  guide-chapters.json     список глав руководства для проверки покрытия
  explorer/               «Справочник Yii 2»: content.py, explorer.css, explorer.js
  php/                    «Справочник PHP 8+»: content.py, sec_*.py, php.css, php.js, data/
  archive/v1/             «Выжимка» — ранняя редакция (17 разделов, один файл)
docs/                     собранный сайт (GitHub Pages)
```

## Сборка

```bash
python3 build.py          # собрать docs/ целиком, включая оба справочника
python3 build.py --check  # только проверить ссылки и покрытие глав, ничего не записывая
```

Отдельные страницы пересобираются своими сборщиками: `python3 build_explorer.py` и `python3 build_php.py`.

Сборка сообщает о неизвестных ссылках и контейнерах, а также о главах руководства, не привязанных ни к одному разделу.

## Формат разделов

Каждый файл в `src/content/` начинается с front matter:

```markdown
---
id: active-record
title: Active Record
part: db
summary: Короткое описание для карточки и поиска.
sources: db-active-record
---
```

Помимо обычного Markdown поддерживаются:

| Синтаксис | Что делает |
|---|---|
| ` ```php title="config/web.php" {1,3-5} ` | блок кода с подписью файла и подсветкой строк |
| `> [!TIP] Заголовок` | врезка (`NOTE`, `TIP`, `WARNING`, `GOTCHA`, `WHY`, `EXAMPLE`) |
| `:::tabs` … `=== Метка` … `:::` | вкладки |
| `:::cols` / `:::cards` / `:::steps` / `:::kv` / `:::details Заголовок` | колонки, карточки, шаги, «ключ — значение», спойлер |
| `:::quiz Проверь себя` + строки `Q:` / `A:` | карточки самопроверки |
| `:::diagram имя` | SVG-диаграмма из `src/diagrams/` |
| `[текст](id-раздела)`, `[текст](guide:slug)`, `[текст](api:yii\web\Controller)` | ссылки на раздел, главу руководства или класс API |

## Выжимка

Ранняя, более сжатая редакция: то же руководство, разложенное на 17 разделов вместо 49 и примерно в семь раз короче по объёму текста. Исходники — в ветке `v1-short`, собранная страница — в `src/archive/v1/index.html`, из курса открывается ссылкой в подвале бокового меню.

## GitHub Pages

В настройках репозитория: **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/docs`, затем **Save**.

Сайт публикуется по адресу https://despro3.github.io/yii2-cheatsheet/. После каждой пересборки достаточно закоммитить изменённую папку `docs/` — Pages обновится сам.

## Справочник

Одна схема на весь экран: двадцать механизмов фреймворка, разложенных по пути запроса, семействам
и фундаменту. Наведение мышью даёт короткую справку, нажатие открывает панель со схемой работы,
полным перечнем всего встроенного, заготовкой своего варианта и граблями. На узком экране под схемой
появляется указатель списком — карта там уезжает в горизонтальную прокрутку.

Состав узлов и их порядок задаются `ORDER` в `src/explorer/content.py`; счётчики в шапке считаются
при сборке, руками их править не нужно. Внутри четыре живые демонстрации: проверка значения
встроенными валидаторами, влияние сценария на атрибуты, жизненный цикл `save()` по шагам и сборка
запроса с показом получаемого SQL.

```bash
python3 build_explorer.py     # соберёт docs/explorer.html
```

Исходники — в `src/explorer/`: `content.py` (все тексты и списки), `explorer.css`, `explorer.js`.

## Справочник PHP 8+

Тот же движок, другой предмет: 27 узлов самого языка — от типов и операторов до перечислений,
файберов, SPL, Composer и PSR. Схема сверху показывает путь кода (запуск → компиляция → опкоды →
выполнение → вывод), ниже четыре семейства возможностей, внизу то, без чего на PHP не пишут.
У каждой возможности в списках отмечена версия, с которой она работает, поэтому фильтр понимает
и «8.3»: наберите номер и увидите, что появилось именно в нём.

Внутри четыре живые демонстрации: сравнение и приведение пары значений, поведение объявленного типа
в обычном и строгом режимах, «строка — это байты» и переключатель версий 8.0–8.5.

```bash
python3 build_php.py          # соберёт docs/php.html
php src/php/data/gen.php      # пересчитать таблицы для демонстраций (нужен PHP 8.4+)
```

Исходники — в `src/php/`: `content.py` (порядок узлов), `sec_*.py` (по файлу на семейство),
`php.css`, `php.js`, `data/` (генераторы таблиц и посчитанный JSON).

Таблицы для двух демонстраций считает сам PHP, а не автор справочника: `src/php/data/gen.php`
перебирает пары значений и объявления типов и записывает результат в `compare.json` и `types.json`.
Пересобирать их нужно, только если меняются списки значений и типов, — на сборку сайта PHP не требуется.
