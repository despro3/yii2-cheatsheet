# Шпаргалка Yii 2.0

Сжатая выжимка [официального руководства Yii 2.0](https://www.yiiframework.com/doc/guide/2.0/ru)
(все 100 глав `guide-ru`) — 17 разделов с примерами кода, которые можно копировать.

**Открыть:** [`index.html`](index.html) — самодостаточный файл, работает локально
двойным щелчком и на GitHub Pages.

## Возможности сайта

- поиск по заголовкам и коду (`/` или `Ctrl`/`Cmd` + `K`, стрелки и `Enter`);
- светлая и тёмная темы (следует системной, переключается кнопкой);
- кнопка «все разделы одной страницей» — для `Ctrl+F` и печати;
- кнопки копирования у каждого блока кода, подсветка синтаксиса;
- содержание текущего раздела справа, навигация по разделам слева;
- адаптивная вёрстка вплоть до ширины телефона.

## Как пересобрать

Контент лежит в Markdown, сайт собирается одним скриптом без зависимостей:

```bash
python3 build.py        # content/*.md + site/* -> index.html
```

```
content/        разделы шпаргалки в Markdown (front matter: id, title, icon, summary)
site/styles.css оформление (токены темы, типографика, компоненты)
site/app.js     поиск, навигация, темы, копирование кода
site/shell.html каркас страницы с плейсхолдерами
build.py        парсер Markdown + сборка одного файла index.html
index.html      результат сборки (коммитится, чтобы открывался без сборки)
```

Источник: официальная документация Yii 2.0, ветка `guide-ru` репозитория
[yiisoft/yii2](https://github.com/yiisoft/yii2/tree/master/docs/guide-ru).
