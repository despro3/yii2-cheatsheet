# Разбор Yii 2

Авторский конспект фреймворка **Yii 2** по официальному [руководству](https://www.yiiframework.com/doc/guide/2.0/ru).

**Открыть сайт → https://despro3.github.io/yii2-cheatsheet/**

Три страницы под три разные задачи:

| Страница | Что это | Когда открывать | Файл |
|---|---|---|---|
| [**Курс по Yii 2**](https://despro3.github.io/yii2-cheatsheet/course.html) | 49 разделов, все 99 глав руководства, примеры, грабли, карточки самопроверки | читать подряд и разбираться | `docs/course.html` |
| [**Справочник Yii 2**](https://despro3.github.io/yii2-cheatsheet/explorer.html) | 18 узлов фреймворка карточками, полные списки встроенного, живые демонстрации | найти нужное и кликнуть | `docs/explorer.html` |
| [**Выжимка по Yii 2**](https://despro3.github.io/yii2-cheatsheet/v1/) | ранняя редакция: то же руководство в 17 разделах вместо 49, в семь раз короче | быстро повторить | `docs/v1/index.html` |

Точка входа — `docs/index.html`: страница-хаб с тремя карточками, откуда расходятся все три. Всё готовое лежит в папке [`docs/`](docs/) и открывается прямо из файла или через GitHub Pages.

## Курс

## Что внутри

- **13 частей** — от установки и структуры приложения до REST, кэширования, тестирования и производительности; порядок разделов выстроен как курс.
- **Код с подсветкой** для PHP, SQL, Bash, JS, JSON, YAML, nginx и других языков; у каждого примера — кнопка копирования.
- **Врезки**: «На заметку», «Совет», «Внимание», «Грабли», «Зачем это нужно», «Пример из жизни».
- **Проверь себя** — карточки «вопрос → ответ» в конце каждого раздела.
- **Поиск** по всем разделам (`Ctrl K` или `/`), оглавление страницы, прогресс изучения, светлая и тёмная темы, версия для печати и «всё одной страницей».
- **Памятка на одну страницу** и **глоссарий** — для быстрого «как это писалось».

Сайт не зависит от внешних скриптов: только HTML, CSS и немного JavaScript. Единственный внешний ресурс — шрифты Google Fonts (без них страница остаётся читаемой на системных шрифтах).

## Структура репозитория

```
build.py                  генератор сайта (Python 3, без зависимостей)
src/
  content/*.md            разделы — Markdown с расширениями
  templates/*.html        каркас страниц и хаб (hub.html)
  assets/                 style.css, app.js, favicon.svg
  diagrams/*.svg          диаграммы
  parts.json              части сайта (порядок, названия, иконки)
  guide-chapters.json     список глав руководства для проверки покрытия
  archive/v1/             «Выжимка» — ранняя редакция (17 разделов, один файл)
docs/                     собранный сайт (GitHub Pages)
```

## Сборка

```bash
python3 build.py          # собрать docs/
python3 build.py --check  # только проверить ссылки и покрытие глав, ничего не записывая
```

Сборка сообщает о неизвестных ссылках и контейнерах, а также о главах руководства, не привязанных ни к одному разделу.

## Формат разделов

Каждый файл в `src/content/` начинается с front matter:

```markdown
---
id: active-record
title: Active Record
part: db
summary: Короткое описание для карточки и поиска.
sources: db-active-record
---
```

Помимо обычного Markdown поддерживаются:

| Синтаксис | Что делает |
|---|---|
| ` ```php title="config/web.php" {1,3-5} ` | блок кода с подписью файла и подсветкой строк |
| `> [!TIP] Заголовок` | врезка (`NOTE`, `TIP`, `WARNING`, `GOTCHA`, `WHY`, `EXAMPLE`) |
| `:::tabs` … `=== Метка` … `:::` | вкладки |
| `:::cols` / `:::cards` / `:::steps` / `:::kv` / `:::details Заголовок` | колонки, карточки, шаги, «ключ — значение», спойлер |
| `:::quiz Проверь себя` + строки `Q:` / `A:` | карточки самопроверки |
| `:::diagram имя` | SVG-диаграмма из `src/diagrams/` |
| `[текст](id-раздела)`, `[текст](guide:slug)`, `[текст](api:yii\web\Controller)` | ссылки на раздел, главу руководства или класс API |

## Выжимка

Ранняя, более сжатая редакция: то же руководство, разложенное на 17 разделов вместо 49 и примерно в семь раз короче по объёму текста. Исходники — в ветке `v1-short`, собранная страница — в `src/archive/v1/index.html`, из курса открывается ссылкой в подвале бокового меню.

## GitHub Pages

В настройках репозитория: **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка `/docs`, затем **Save**.

Сайт публикуется по адресу https://despro3.github.io/yii2-cheatsheet/. После каждой пересборки достаточно закоммитить изменённую папку `docs/` — Pages обновится сам.

## Справочник

Отдельная страница-каталог: восемнадцать основных механизмов фреймворка карточками, каждая раскрывается
в панель со схемой работы, полным перечнем всего встроенного, заготовкой своего варианта и граблями.
Список узлов и их сквозная нумерация задаются `ORDER` в `src/explorer/content.py`; числа в шапке
каталога и на карточке главной считаются при сборке, руками их править не нужно.
Внутри четыре живые демонстрации: проверка значения встроенными валидаторами, влияние сценария на
атрибуты, жизненный цикл `save()` по шагам и сборка запроса с показом получаемого SQL.

```bash
python3 build_explorer.py     # соберёт docs/explorer.html
```

Исходники — в `src/explorer/`: `content.py` (все тексты и списки), `explorer.css`, `explorer.js`.
