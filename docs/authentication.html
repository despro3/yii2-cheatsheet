33Аутентификация

Компонент user и IdentityInterface — findIdentity, findIdentityByAccessToken, getId, getAuthKey, validateAuthKey; login/logout/isGuest/identity, «запомнить меня» через cookie, тайм-ауты сессии, события beforeLogin/afterLogin, returnUrl, доступ только для авторизованных.

⏱ ~5 мин 📚 1 глава руководства

Аутентификация отвечает на вопрос «кто это?». В Yii за неё отвечает компонент Yii::$app->user (класс yii\web\User), а сведения о пользователе хранит identity-класс, реализующий IdentityInterface. Проверка пароля — ваша, остальное (сессия, cookie, тайм-ауты, события) — фреймворка.

Настройка#

Identity-класс#

findIdentity($id)
найти пользователя по ID; вызывается при каждом запросе с сессией
findIdentityByAccessToken($token, $type)
по токену (REST); $type — класс аутентификатора
getId()
уникальный ID, кладётся в сессию
getAuthKey()
секрет для cookie автологина; храните в БД, генерируйте при регистрации, меняйте при смене пароля
validateAuthKey($key)
сверка ключа из cookie

Identity не обязан быть Active Record — подойдёт любой класс (LDAP, внешний API, массив в конфиге).

Вход и выход#

login($identity, $duration): при $duration > 0 и enableAutoLogin ставится cookie с ID + authKey на указанный срок. Пароль проверяется в вашем коде (validatePassword) до вызова login().

Текущий пользователь#

identity загружается лениво один раз за запрос — findIdentity() вызовется только если к нему обратились.

Доступ только для вошедших#

Гость получит редирект на loginUrl; после входа goBack() вернёт его туда, откуда он пришёл. Подробнее — в авторизации.

Как это работает под капотом#

  1. Первый запрос: user->login() кладёт getId() в сессию (__id) и, при $duration, ставит identity-cookie [id, authKey, duration].
  2. Следующие запросы: user->identity читает ID из сессии → findIdentity($id).
  3. Сессии нет, но есть cookie: сравнивается authKey через validateAuthKey() → авто-вход, сессия продлевается (autoRenewCookie).
  4. authTimeout/absoluteAuthTimeout проверяются на каждом запросе; истёк — logout().
  5. REST без сессии (enableSession = false): findIdentityByAccessToken() вызывает аутентификатор из фильтров (HttpBearerAuth и др.).

События#

beforeLogin
$event->isValid = false отменяет вход; $event->identity, $event->cookieBased, $event->duration
afterLogin
вход выполнен
beforeLogout / afterLogout
аналогично
Безопасность authKey

getAuthKey() — фактически второй пароль в cookie. Генерируйте его криптографически (generateRandomString()), никогда не возвращайте константу, меняйте при смене пароля и выходе «со всех устройств». access_token для API — тоже случайная строка, не хэш ID.

Проверь себя5

findIdentity(), findIdentityByAccessToken(), getId(), getAuthKey(), validateAuthKey().

Ваш код: Yii::$app->security->validatePassword() до вызова Yii::$app->user->login().

enableAutoLogin = true, duration > 0 в login() и корректные getAuthKey()/validateAuthKey().

Первый — выход после N секунд бездействия (продлевается каждым запросом), второй — через N секунд после входа независимо от активности.

Yii::$app->user->loginRequired() (или AccessControl) сохраняет returnUrl; после входа — $this->goBack().
