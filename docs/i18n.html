43Интернационализация

language и sourceLanguage, Yii::t() с параметрами, множественным числом, select, number и date (ICU MessageFormat), источники переводов PhpMessageSource/DbMessageSource/GettextMessageSource, извлечение сообщений командой message, переводы представлений и модулей, локаль форматтера.

⏱ ~5 мин 📚 1 глава руководства

I18n в Yii — это три вещи: язык приложения (Yii::$app->language), перевод сообщений через Yii::t() с форматированием ICU и локализация вывода дат/чисел через formatter. Строки пишутся на исходном языке (обычно английском), переводы хранятся в файлах или БД по категориям.

Языки#

Код языка — IETF: en, en-US, ru-RU, zh-Hans-CN. Если для ru-RU перевода нет, будет искаться ru.

Yii::t()#

Категория (app) — группа сообщений; yii зарезервирована для фреймворка, расширения используют свои (yii/bootstrap...). Если строка не переведена, вернётся исходная (и сработает событие missingTranslation).

Множественное число#

Формы для русского перевода — one, few, many, other (правила CLDR):

# — число, =0 — точное значение. Также {n, plural, offset:1 …} и {n, selectordinal, one{#st} two{#nd} few{#rd} other{#th}}.

Выбор по значению#

Числа, даты, порядковые#

Всё это MessageFormatter расширения intl; без intl доступны только простые подстановки, plural и select.

Источники переводов#

PhpMessageSource
PHP-массивы basePath/<язык>/<категория>.php; самый быстрый и простой
DbMessageSource
таблицы source_message и message (миграция @yii/i18n/migrations); переводы редактируются в админке
GettextMessageSource
файлы .po/.mo, инструменты переводчиков

Ключ app* — маска по префиксу. Переводы фреймворка (yii) уже есть на десятках языков — категорию yii настраивать не нужно.

Извлечение сообщений#

Команда находит все вызовы Yii::t() (и \Yii::t, $this->t в шаблонах — настраивается translator), создаёт файлы для каждого языка, помечает удалённые строки @@…@@, сортирует. Для БД — 'format' => 'db', для gettext — 'po'.

Переводы в разных местах#

Локаль форматтера и прочее#

  • Yii::$app->formatter->locale по умолчанию = language — даты и числа локализуются автоматически.
  • Yii::$app->language влияет на Html::tag('html', …, ['lang' => …]) — задавайте lang в layout из Yii::$app->language.
  • RTL-языки: Yii::$app->formatter не решает вёрстку — используйте класс dir="rtl" в layout по языку.
  • URL с языком (/ru/site/about) — свой UrlManager или правило с параметром <lang:(ru|en)> и установка языка в beforeAction/bootstrap; готовые расширения: codemix/yii2-localeurls.
Проверь себя5

Исходную строку Hello и вызовет событие missingTranslation у источника.

Зарегистрировать источник в Yii::$app->i18n->translations под своей категорией (обычно в init() модуля) и использовать эту категорию в Yii::t().
