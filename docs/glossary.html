48Глоссарий

Ключевые термины Yii 2 в алфавитном порядке с короткими определениями и ссылками на разделы, где о них рассказано подробно.

⏱ ~5 мин 🧷 сводный раздел

Короткие определения терминов, которые встречаются по всему руководству. Ссылка ведёт в раздел, где термин разобран.

А–Д#

Active Record (AR)
класс, представляющий строку таблицы: атрибуты = столбцы, save()/delete(), связи hasOne/hasMany. → Active Record
ActiveDataProvider
провайдер данных, который берёт страницу моделей из ActiveQuery с пагинацией и сортировкой. → Провайдеры данных
ActiveForm / ActiveField
виджет формы и одно её поле, привязанные к модели: label, input, ошибка, JS-валидация. → Формы
ActiveQuery
объект запроса для AR (наследует Query): where(), with(), joinWith(), all(). → Active Record
Asset Bundle
класс с набором CSS/JS-файлов и зависимостями; регистрируется в представлении и публикуется в web/assets. → Ассеты
ACF (Access Control Filter)
фильтр AccessControl с правилами allow/deny по ролям, IP, методам. → Авторизация
Псевдоним (alias)
имя вида @app, заменяющее путь или URL; Yii::getAlias(). → Конфигурации
Действие (action)
метод контроллера actionXxx() или класс Action; конечная точка маршрута. → Контроллеры
Автозагрузка
поиск файла класса по namespace и псевдониму (app\models\User → @app/models/User.php). → Конфигурации
Аутентификация
установление личности пользователя; компонент user + IdentityInterface. → Аутентификация
Авторизация
проверка прав: ACF или RBAC (can()). → Авторизация
Бутстрап (bootstrap)
компоненты/классы, инициализируемые при старте приложения ('bootstrap' => ['log'], BootstrapInterface). → Жизненный цикл
Behavior (поведение)
объект, добавляющий компоненту методы, свойства и обработчики событий без наследования. → Поведения
Валидатор
класс правила проверки (required, email, свой). → Валидация, Валидаторы
Виджет
переиспользуемый блок представления (Widget::widget() / begin()…end()). → Виджеты
Входной скрипт
web/index.php / yii: подключает автозагрузчик, создаёт приложение, run(). → Приложение
Грязные атрибуты (dirty)
изменённые после загрузки атрибуты AR; только они попадают в UPDATE. → Active Record
DAO
Data Access Objects: Connection/Command — работа с SQL напрямую, с привязкой параметров. → DAO
DI-контейнер
Yii::$container: создаёт объекты, разрешая зависимости по типам конструктора. → DI
DataProvider
источник постраничных данных для GridView/ListView/REST. → Провайдеры данных
Зависимость кэша
условие инвалидации (TagDependency, DbDependency, FileDependency…). → Кэширование данных

Ж–П#

Жадная загрузка (eager)
with('rel'): связанные записи одним запросом для всех моделей; против N+1. → Active Record
Ленивая загрузка (lazy)
$model->rel: запрос при первом обращении. → Active Record
Компонент
yii\base\Component: свойства, события, поведения. Компонент приложения — Yii::$app->id. → Компоненты
Конфигурация
массив ['class' => …, 'prop' => …], описывающий объект; Yii::createObject(). → Конфигурации
Контроллер
класс, группирующий действия; Controller → render(), redirect(). → Контроллеры
Layout (шаблон)
общая обёртка страниц (views/layouts/main.php), получает $content. → Представления
Массовое присваивание
$model->attributes = $data / load(); только безопасные атрибуты. → Модели
Миграция
класс, меняющий схему БД, с up()/down(); команда migrate. → Миграции
Модель
yii\base\Model: атрибуты, правила, сценарии, подписи, ошибки. → Модели
Модуль
мини-приложение с контроллерами, моделями и представлениями; modules в конфигурации. → Модули
Маршрут (route)
строка module/controller/action; urlManager разбирает и строит URL. → Маршрутизация
N+1
1 запрос за списком + по запросу на связь каждой строки; лечится with(). → Active Record
Оптимистичная блокировка
столбец версии; при несовпадении StaleObjectException. → Active Record
Пагинация
Pagination + LinkPager: page, per-page, offset/limit. → Провайдеры данных
Параметры (params)
Yii::$app->params['adminEmail'] — произвольные настройки приложения. → Приложение
Провайдер данных
см. DataProvider.
Представление (view)
PHP-шаблон в views/; $this — yii\web\View. → Представления

Р–Я#

RBAC
управление доступом на основе ролей: разрешения, роли, правила, authManager. → Авторизация
REST
yii\rest\ActiveController + UrlRule: CRUD-API поверх AR. → REST
Расширение
Composer-пакет yii2-extension с bootstrap и псевдонимами. → Расширения
Связь (relation)
hasOne/hasMany (+via/viaTable) между AR-классами. → Active Record
Сервис-локатор
Yii::$app/модуль: хранит компоненты по ID, создаёт лениво. → DI
Сессия
Yii::$app->session: данные между запросами; flash-сообщения. → Сессии и cookie
Событие
on()/trigger(); Event с sender, data, handled, isValid. → События
Сценарий (scenario)
режим модели, определяющий активные правила и безопасные атрибуты. → Модели
Тема (theme)
подмена путей представлений (pathMap) без изменения кода. → Представления
Фильтр
поведение контроллера с beforeAction/afterAction: AccessControl, VerbFilter, PageCache, Cors… → Фильтры
Фикстура
воспроизводимые данные для тестов (ActiveFixture). → Тестирование
Форматтер
Yii::$app->formatter: asDate, asCurrency, asSize… → Форматирование
Фрагментное кэширование
beginCache()/endCache() в представлении. → Кэширование вывода
Хелпер
статический класс-утилита: Html, Url, ArrayHelper, Json. → Хелперы
Шаблон приложения
basic (одно приложение) или advanced (frontend/backend/console/common). → Установка
CSRF
подделка межсайтовых запросов; токен _csrf в формах и заголовке. → Безопасность
Gii
генератор кода: модели, CRUD, контроллеры, модули. → Инструменты
HATEOAS
ссылки _links в ответах API (Linkable). → REST
Identity
класс, реализующий IdentityInterface; Yii::$app->user->identity. → Аутентификация
i18n
интернационализация: Yii::t(), источники переводов, ICU-формат. → i18n
Pjax
виджет, обновляющий часть страницы через AJAX + pushState. → Виджеты
Query Builder
yii\db\Query: объектная сборка SQL под любую СУБД. → Query Builder
Response
Yii::$app->response: статус, заголовки, формат, sendFile(). → Запрос и ответ
Service Locator
см. Сервис-локатор.
UrlManager
компонент разбора и генерации URL по правилам. → Маршрутизация
View (объект)
yii\web\View: render(), registerJs(), title, params, блоки. → Представления
