# Работа с БД: DAO и построитель запросов

Три уровня работы с базой: **DAO** (чистый SQL поверх PDO) → **Query Builder** (массивы
вместо SQL) → **Active Record** (объекты). Все три можно смешивать.

## Подключение

```php
'db' => [
    'class' => 'yii\db\Connection',
    'dsn' => 'mysql:host=localhost;dbname=example',
    'username' => 'root',
    'password' => '',
    'charset' => 'utf8mb4',
    'tablePrefix' => 'tbl_',
    'enableSchemaCache' => true,          // кеш схемы — обязателен на продакшене
    'schemaCacheDuration' => 3600,
    'schemaCache' => 'cache',
    'on afterOpen' => function ($event) {
        $event->sender->createCommand("SET time_zone = '+00:00'")->execute();
    },
],
```

| СУБД | DSN |
|---|---|
| MySQL / MariaDB | `mysql:host=localhost;dbname=mydb` |
| PostgreSQL | `pgsql:host=localhost;port=5432;dbname=mydb` |
| SQLite | `sqlite:/path/to/db.sqlite` |
| MS SQL | `sqlsrv:Server=localhost;Database=mydb` |
| Oracle | `oci:dbname=//localhost:1521/mydb` |
| ODBC | `odbc:Driver={MySQL};...` + обязательно `driverName` |

Соединение открывается лениво — при первом запросе или `open()`.

## Command: SQL напрямую

```php
$db = Yii::$app->db;

$posts  = $db->createCommand('SELECT * FROM post')->queryAll();      // [] если пусто
$post   = $db->createCommand('SELECT * FROM post WHERE id=1')->queryOne();  // false если пусто
$titles = $db->createCommand('SELECT title FROM post')->queryColumn();
$count  = $db->createCommand('SELECT COUNT(*) FROM post')->queryScalar();

$rows = $db->createCommand('UPDATE post SET status=1 WHERE id=1')->execute();  // кол-во строк
```

### Привязка параметров — всегда

```php
$post = $db->createCommand('SELECT * FROM post WHERE id=:id AND status=:s')
    ->bindValue(':id', $id)
    ->bindValue(':s', 1)
    ->queryOne();

// или сразу
$db->createCommand($sql, [':id' => $id, ':s' => 1])->queryOne();

// bindParam() привязывает по ссылке — удобно в циклах (запрос готовится один раз)
$command = $db->createCommand('SELECT * FROM post WHERE id=:id')->bindParam(':id', $id);
foreach ([1, 2, 3] as $id) { $rows[] = $command->queryOne(); }
```

### Готовые CRUD-команды

```php
$db->createCommand()->insert('user', ['name' => 'Sam', 'age' => 30])->execute();
$db->createCommand()->batchInsert('user', ['name', 'age'], [
    ['Tom', 30], ['Jane', 20],
])->execute();
$db->createCommand()->update('user', ['status' => 1], 'age > 30')->execute();
$db->createCommand()->delete('user', ['status' => 0])->execute();
$db->createCommand()->upsert('user', ['email' => 'a@b.c', 'hits' => 1], ['hits' => new Expression('hits + 1')])->execute();
$db->getLastInsertID();
```

### Экранирование имён

```php
// [[столбец]] и {{таблица}}; {{%таблица}} подставляет tablePrefix
$db->createCommand("SELECT COUNT([[id]]) FROM {{%employee}}")->queryScalar();
```

## Транзакции

```php
// краткая форма
Yii::$app->db->transaction(function ($db) {
    $db->createCommand($sql1)->execute();
    $db->createCommand($sql2)->execute();
}, \yii\db\Transaction::REPEATABLE_READ);

// полный контроль
$transaction = Yii::$app->db->beginTransaction();
try {
    // ...
    $transaction->commit();
} catch (\Throwable $e) {
    $transaction->rollBack();
    throw $e;
}
```

Уровни изоляции: `READ_UNCOMMITTED`, `READ_COMMITTED`, `REPEATABLE_READ`, `SERIALIZABLE`.
Вложенные транзакции работают через SAVEPOINT, если СУБД их поддерживает.

> Важно: SQLite поддерживает только `READ UNCOMMITTED` и `SERIALIZABLE`; PostgreSQL не даёт
> задать уровень до старта транзакции — используйте `setIsolationLevel()` после старта.

## Репликация: master/slave

```php
[
    'class' => 'yii\db\Connection',
    'dsn' => 'мастер',
    'username' => 'master', 'password' => '',
    'slaveConfig' => ['username' => 'slave', 'password' => '',
                      'attributes' => [PDO::ATTR_TIMEOUT => 10]],
    'slaves' => [
        ['dsn' => 'слейв 1'],
        ['dsn' => 'слейв 2'],
    ],
    // либо несколько мастеров: 'masters' => [...], 'masterConfig' => [...]
]
```

`execute()` идёт на мастер, `queryXxx()` — на случайный живой слейв (есть failover и
кеш статуса серверов). Транзакции всегда на мастере. Принудительно:

```php
$rows = Yii::$app->db->useMaster(fn ($db) => $db->createCommand($sql)->queryAll());
Yii::$app->db->enableSlaves = false;
```

## Схема БД

```php
$db->createCommand()->createTable('post', ['id' => 'pk', 'title' => 'string', 'text' => 'text'])->execute();
```

Методы `Command`: `createTable`, `renameTable`, `dropTable`, `truncateTable`, `addColumn`,
`renameColumn`, `alterColumn`, `dropColumn`, `addPrimaryKey`, `dropPrimaryKey`,
`addForeignKey`, `dropForeignKey`, `createIndex`, `dropIndex`, `addCommentOnColumn`.

```php
$table = Yii::$app->db->getTableSchema('post');   // yii\db\TableSchema
$table->columns['title']->type;
$table->primaryKey;
Yii::$app->db->schema->getTableNames();
```

## Построитель запросов

```php
use yii\db\Query;

$rows = (new Query())
    ->select(['id', 'email'])
    ->from('user')
    ->where(['last_name' => 'Smith'])
    ->limit(10)
    ->all();
```

### SELECT / FROM

```php
$query->select(['user_id' => 'user.id', 'email']);            // алиасы через ключи
$query->select(["CONCAT(first_name,' ',last_name) AS full_name"]);
$query->addSelect(['created_at'])->distinct();
$query->from(['u' => 'public.user', 'p' => 'public.post']);

$sub = (new Query())->select('COUNT(*)')->from('user');
$query->select(['id', 'count' => $sub])->from('post');        // подзапрос в SELECT
$query->from(['u' => $sub]);                                  // подзапрос во FROM
```

### WHERE — три формата

```php
// 1. строка (только с привязкой параметров!)
$query->where('status=:status', [':status' => $status]);

// 2. хеш — равенства через AND, корректно обрабатывает null и массивы
$query->where(['status' => 10, 'type' => null, 'id' => [4, 8, 15]]);
// WHERE (status=10) AND (type IS NULL) AND (id IN (4,8,15))

// 3. операторы
$query->where(['and', ['status' => 1], ['or', ['>', 'age', 30], ['type' => 2]]]);
```

| Оператор | Пример | SQL |
|---|---|---|
| `and`, `or` | `['or', 'id=1', 'id=2']` | `id=1 OR id=2` |
| `not` | `['not', ['status' => 1]]` | `NOT (status=1)` |
| `between` / `not between` | `['between', 'id', 1, 10]` | `id BETWEEN 1 AND 10` |
| `in` / `not in` | `['in', 'id', [1,2,3]]` | `id IN (1,2,3)`; второй операнд может быть `Query` |
| `like` / `or like` / `not like` | `['like', 'name', 'test']` | `name LIKE '%test%'` |
| `exists` / `not exists` | `['exists', $subQuery]` | `EXISTS (...)` |
| `>`, `<`, `>=`, `<=`, `!=` | `['>', 'age', 10]` | `age>10` |

```php
$query->andWhere(['like', 'title', $search])->orWhere(['author_id' => 1]);

// filterWhere игнорирует пустые значения (null, '', [], пробелы) — для форм поиска
$query->filterWhere(['username' => $username, 'email' => $email])
      ->andFilterWhere(['like', 'name', $name]);
```

> Важно: значения **всегда** параметризуются, а **имена столбцов — нет**. Никогда не
> подставляйте имя столбца из пользовательского ввода без белого списка:
> `$query->where([$request->get('column') => $value])` — SQL-инъекция.

### Остальные части запроса

```php
$query->orderBy(['id' => SORT_ASC, 'name' => SORT_DESC])->addOrderBy('age');
$query->groupBy(['id', 'status'])->addGroupBy('age');
$query->having(['status' => 1])->andHaving(['>', 'age', 30]);
$query->limit(10)->offset(20);

$query->join('LEFT JOIN', 'post', 'post.user_id = user.id');
$query->innerJoin('post', 'post.user_id = user.id');
$query->leftJoin(['u' => $subQuery], 'u.id = author_id');
$query->union($otherQuery);
$query->withQuery($cteQuery, 'cte');      // CTE, с 2.0.35
```

> Важно: в условии `ON` нельзя использовать хеш-формат — `['user.id' => 'comment.user_id']`
> сравнит столбец со **строкой**. Пишите строкой: `'user.id = comment.user_id'`.

### Выполнение

```php
$query->all();      // массив строк
$query->one();      // первая строка (LIMIT не добавляется — ставьте limit(1) сами)
$query->column();   // первый столбец
$query->scalar();   // одно значение
$query->exists();   // bool
$query->count();  $query->sum('x');  $query->average('x');  $query->max('x');  $query->min('x');

$query->indexBy('id')->all();                       // индексация результата
$query->indexBy(fn ($row) => $row['id'] . $row['username'])->all();

foreach ($query->batch(100) as $rows) { }           // пакетами по 100
foreach ($query->each(100) as $row) { }             // по одной строке, память экономится

// Посмотреть SQL
$command = $query->createCommand();
echo $command->getRawSql();          // с подставленными параметрами
echo $command->sql; print_r($command->params);
```

> Совет: любой `Query` можно выполнить на другом соединении — передайте его в метод
> выборки: `$query->all($db2)`.
